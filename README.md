# Пары КТК

Нативное приложение Android с недельным расписанием Канского технологического колледжа. При первом запуске выберите свою группу из списка колледжа. Приложение запомнит выбор. Чтобы сменить группу, нажмите «Группа». Приложение получает данные с сервера ПроКолледжа. Кнопка «Кабинет» открывает страницу входа в браузере.

Для сборки откройте проект в Android Studio с Android SDK 34 и JDK 17. Выберите Build APK или запустите проект на устройстве с Android 6.0 или новее.

## Релизы

Каждое обновление публикуется в GitHub Releases с тегом версии и подписанным APK. Перед выпуском увеличьте versionCode и обновите versionName в app/build.gradle. Подписывайте APK тем же ключом, что и предыдущие выпуски, чтобы пользователи могли установить обновление поверх старой версии. Храните ключ вне репозитория.

Для новой установки или обновления скачайте APK из последнего релиза и откройте его на телефоне.
