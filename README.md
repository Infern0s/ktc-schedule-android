# Пары КТК

Нативное приложение Android с недельным расписанием Канского технологического колледжа. Стартовая группа РП.09.24.1. Приложение получает данные с сервера ПроКолледжа. Кнопка «Кабинет» открывает страницу входа в браузере.

Для сборки откройте проект в Android Studio с Android SDK 34 и JDK 17. Выберите Build APK или запустите проект на устройстве с Android 6.0 или новее.
