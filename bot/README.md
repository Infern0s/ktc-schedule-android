# Пары КТК в Telegram

Бот показывает открытое расписание колледжа. В главном меню выберите группу или преподавателя. Поиск принимает часть названия группы или фамилии. В расписании можно переключать недели и смотреть только сегодняшний день. Список преподавателей формируется по фактическим парам выбранной недели.

## Локальный запуск

Нужен Node.js 22 или новее. Отдельных пакетов и расширений VS Code для запуска не требуется.

1. Создайте бота через BotFather.
2. Запишите токен в файл bot/.env в виде TELEGRAM_BOT_TOKEN=токен. Файл исключён из Git.
3. Откройте корень репозитория в VS Code и запустите конфигурацию «Пары КТК · Telegram» через Run and Debug.

Из терминала в папке bot используйте команду node --env-file=.env bot.mjs. Бот доступен в Telegram, пока процесс запущен и компьютер подключён к интернету.
